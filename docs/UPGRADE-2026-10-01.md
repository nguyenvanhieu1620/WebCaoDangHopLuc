## Phân công và kết quả

Claude Code 2.1.283 được gọi thực sự qua CLI. Claude sửa đúng 3 file giao: trang admin tuyển sinh, trang đăng nhập và SiteHeader. Hoàn tất exit code 0. Claude không chạy được các lệnh kiểm tra do quyền CLI; Codex đã thực hiện kiểm tra thay vì coi phản hồi Claude là bằng chứng hoàn tất. Hai bên ghi file lần lượt trong cùng thư mục.

Codex tạo/tối ưu hai asset 3D, triển khai ProgramExplorer và các trang công khai, sửa carousel theo review chéo, đối chiếu diff và thử Chrome. Claude được gọi thêm lần review chỉ đọc: phát hiện banner ẩn vẫn có thể nhận focus, carousel thiếu tạm dừng/reduced-motion, menu hover chưa đóng bằng Escape và trang ngành thiếu h1. Codex xử lý các điểm này. Nhận xét nghi ngờ build do useSearchParams không tái hiện: build production đạt, route login được render động.

## Kiểm tra

- TypeScript: đạt.
- ESLint: đạt.
- `npm test`: 36/36 đạt; DB của test API là SQLite memory riêng.
- `npm run build`: đạt, 49 trang được sinh; các trang dữ liệu/auth là dynamic.

Bao gồm ảnh 3D tải được, tìm không dấu, empty state, giới hạn 3 lựa chọn, CTA prefill, đăng nhập sau mật khẩu sai giữ email, toggle mật khẩu, Chi tiết hồ sơ, bảng mobile cuộn được, so sánh mobile không tràn ngang, menu bàn phím/mobile và hero reduced-motion.

- Dev server port 3000 được xác minh và khởi động lại vì trang quản trị vẫn phục vụ bản cũ sau thay đổi. Server hiện phục vụ mã mới.

Ảnh và JSON chứng cứ tại [upgrade-2026-10](upgrade-2026-10/), đặc biệt `browser-results.json`, `flows.json`, `home-desktop.png`, `home-mobile.png`, `program-comparison-desktop.png`, `program-comparison-mobile.png`, `admin-admissions-mobile-scrolled.png`.
